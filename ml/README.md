# Tourism Intelligence ML Engine

Machine-learning component for the DOSM Tourism Datathon.

## Responsibilities

1. Forecast tourism demand momentum.
2. Calculate interpretable opportunity and pressure scores.
3. Generate tourism intelligence outputs for the dashboard.
4. Provide signals for JomExplore destination recommendations.

## Current Data Scope

- State tourism indicators
- District socioeconomic indicators
- Monthly Google Trends data
- DOSM destination rankings

## Important Limitations

- Tourism demand and spending are mainly available at state level.
- District-level tourist arrivals are not available.
- Pressure scores represent regional context, not attraction-level crowding.
- The available data is historical and periodically refreshed, not real-time.

Malaysia Tourism Datathon Deliverables

cleaned_data.csv
Primary state-year dashboard table. It combines state tourism performance, calculated tourism indicators, Google Search Interest, prosperity context, and rule-based opportunity/pressure labels.

chart_data/tourism_trend.csv
State-year trend table for line charts covering visitors, receipts, growth, tourism intensity, and search interest.

chart_data/state_comparison.csv
Latest-year state comparison table for ranking states by visitors, receipts, growth, spending per visitor, intensity, and digital interest.

chart_data/segment_summary.csv
Aggregated summary of states by opportunity and pressure pattern.

chart_data/map_data.csv
District-level context table for map joins. It has district names but no coordinates or geometry because those were not included in the uploaded data.

Indicator notes
Tourism Growth = annual domestic visitor growth.
Spending per Visitor = tourism receipts per domestic visitor, from Table 1 average receipts per capita.
Trips per Visitor = domestic trips divided by domestic visitors.
Tourism Intensity = domestic visitors divided by resident population.
Tourism Value Growth = annual tourism receipts growth.
Local Prosperity Context = rule label from income and poverty where HIES data exists.
Google Search Interest = annual average Google Trends index.
Search Interest Growth = year-on-year change in Google Search Interest.
Digital Interest Trend = categorical label from Search Interest Growth.
Emerging Viral Destination = search-interest proxy based on Google Trends growth and level.
Opportunity Pattern = rule-based signal using tourism growth, search growth, intensity, and poverty.
Pressure Pattern = rule-based signal using high tourism intensity plus positive growth/search momentum.
